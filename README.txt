# Galaxia de Flores Amarillas 🌻

Proyecto ordenado a partir del `index.html` original.

## Estructura
- `index.html`: página principal y configuración/animaciones del proyecto.
- `js/`: librerías Three.js y postprocesado separadas del HTML.
- `assets/`: carpeta reservada para recursos externos si posteriormente quieres separar imágenes/audio.

## Cómo abrir
Abre `index.html` en un navegador moderno. Si alguna función del navegador bloquea recursos locales, puedes servir la carpeta con un servidor local (por ejemplo, Live Server).
